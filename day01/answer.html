🐍 Python 변수 연습문제

변수와 기본 자료형을 복습해 봅시다.

문제 1. 변수 만들기

이름, 나이, 키를 각각 변수에 저장하고 출력하세요.

출력 결과

이름: 홍길동
나이: 20
키: 175.5

문제 2. 변수의 값 변경하기

다음 코드에서 score의 값을 90으로 변경한 후 출력하세요. 

score = 70

# 여기에 코드 작성

print(score)

출력 결과

90

문제 3. 변수 계산하기

다음 두 변수를 이용하여 더하기, 빼기, 곱하기 결과를 출력하세요. 

num01 = 20
num02 = 10

출력 결과

더하기: 30
빼기: 10
곱하기: 200

문제 4. 자료형 확인하기

다음 변수들의 자료형을 type()을 이용하여 출력하세요. 

name = "홍길동"
age = 20
height = 175.5
is_student = True
💡 int, float, str, bool 중 어떤 자료형인지 확인해 보세요.

문제 5. 자료형 변환하기

다음 숫자를 문자열로 변환하여 출력하세요. 

age = 20

# 여기에 코드 작성

출력 결과

내 나이는 20살입니다.
💡 str()을 사용하세요.

문제 6. 리스트 값 출력하기

다음 리스트가 있습니다.

fruits = ["apple", "banana", "mango"]

인덱스를 이용하여 banana를 출력하세요.

💡 리스트의 인덱스는 0부터 시작합니다.

문제 7. 리스트 값 변경하기

다음 리스트가 있습니다.

fruits = ["apple", "banana", "mango"]

banana를 strawberry로 변경하세요.

최종 결과

['apple', 'strawberry', 'mango']

문제 8. 리스트에 값 추가하기

다음 리스트가 있습니다.

fruits = ["apple", "banana", "mango"]

리스트 마지막에 "peach"를 추가하세요.

최종 결과

['apple', 'banana', 'mango', 'peach']
💡 append()를 사용하세요.

문제 9. 튜플을 리스트로 변환하기

다음 튜플이 있습니다.

colors = ("red", "green", "blue")

튜플을 리스트로 변환한 후 "yellow"를 추가하세요.

최종 결과

['red', 'green', 'blue', 'yellow']
💡 list()와 append()를 사용하세요.

문제 10. 딕셔너리 값 출력하기

다음 학생 정보가 있습니다.

student = {
    "name": "홍길동",
    "age": 20,
    "score": 85
}

딕셔너리의 key를 이용하여 다음과 같이 출력하세요. 

학생 이름: 홍길동
나이: 20
점수: 85
💡 student["name"]과 같은 방법으로 값을 가져올 수 있습니다.
